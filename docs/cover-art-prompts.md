# 選曲画面のカバーイラストを作る

選曲カードに載せる 16:9 のカバーイラストを ChatGPT の画像生成で作るための
プロンプト集。曲を足したときは、この型に沿って 1 本足す。

## 作り方

1. **新規チャット 1 つにつき 1 曲。** 前の曲の絵に引きずられるので使い回さない。
2. 参考画像として `public/assets/hosomi/IDLE_00.webp` を添付する。傘・頭のハート・
   音符のバンダナが全部写っているコマなら他でもよい。
3. 下のプロンプトをそのまま貼る。
4. タイトルの文字が崩れたら「リトライ用」を送る。1〜2 回で直ることが多い。
5. できた画像を 16:9 に切って WebP にし、`public/assets/covers/<songId>.webp` に置く。

### 4 枚の共通ルール

絵柄・画角・キャラの大きさを揃えるため、以下は全曲で固定している。曲ごとに変えるのは
情景・光の色・ポーズ・ロゴの色だけ。

- 右 1/3 にホソミの全身(画面の高さの 75%)、左 2/3 にタイトルロゴ
- タイトルは 2 段組み。上段に小さく「ホソミ」、下段に大きく曲名の残り
- ぷっくりした丸文字のかわいい飾り文字。白いハイライトと太い縁取り
- 曲名以外の文字を描かせない(放っておくと英字やロゴマークが混ざる)

### サイズの都合

ChatGPT の画像生成は横長だと **1536×1024(3:2)** で出る。16:9 ちょうどは出ないので、
上下を切って 1536×864 にする前提でプロンプトを書いてある。「上端 12% と下端 12% には
文字もキャラも置かない」という指示がそれ。ここを削ると切ったときに頭やロゴの端が飛ぶ。

切り出しと変換:

```bash
sips -c 864 1536 cover.png --out cover-crop.png && cwebp -q 85 cover-crop.png -o public/assets/covers/amedance.webp
```

`sips -c` は中央を基準に切るので、上下から 72px ずつ落ちる。`cwebp` が無ければ
`brew install webp` で入る。

## ホソミアメダンス

```text
添付した画像のキャラクターを主役にした、横長ワイドのカバーイラストを1枚描いてください。

【キャラクター】添付のキャラをそのまま使うこと。造形を変えない。
- クリーム色のまるい体、短い手足、黒い点の目、ほおの丸いチーク
- 頭から伸びる細い触角の先にピンクのハート
- 首に白い音符マークが入ったピンクのバンダナ
- 半透明の青いビニール傘

【絵柄】添付と同じ絵柄。太さの均一な黒い輪郭線、セル塗り、やわらかいグラデーションの影。絵本のようなカワイイアニメ調。

【サイズ・構図】横長ワイド（1536×1024）。
- 画面の右3分の1にキャラの全身。頭の先から足元まで、画面の高さの75%を占める
- 画面の左3分の2にタイトルロゴ
- あとで上下を切って16:9にするので、画面の上端12%と下端12%には文字もキャラも置かない。そこは背景だけにする

【ポーズ】ダイナミックに。つま先立ちで片足を高く跳ね上げ、体をひねりながら回転している最中。傘を高く掲げ、傘といっしょに水しぶきが円弧を描いて舞う。目を細めて笑っている。

【情景】夕暮れのバス停のわき。しとしと降る雨、足元は水たまり。街灯のあたたかいオレンジの光が濡れた地面に反射する。空気は藤色から青紫の薄暮。しずくがきらきら光っている。

【タイトルロゴ】画面左側に、大きく、かわいい飾り文字で2段に配置する。
- 上段（小さめ）: ホ ソ ミ  ← カタカナ3文字
- 下段（大きく、左半分の幅いっぱい）: ア メ ダ ン ス  ← カタカナ5文字
- ぷっくりふくらんだ丸文字。飴玉のようなツヤがあり、文字の上のほうに白いハイライトが入る
- 白い文字に、パステルの藤色の太い縁取りと、そのさらに外に白い縁。うしろに柔らかい影
- 一文字ずつ少し傾けて弾むように並べ、すきまに小さなしずく・水玉・星のきらめきを散らす
- 文字は上に書いたカタカナと完全に一致させること。1文字も足さない、変えない

【禁止】タイトル以外の文字を一切描かない。英字・アルファベット・数字・署名・透かし・ロゴマークを入れない。手足を増やさない。
```

## リトライ用

タイトルの文字が崩れたときに送る。曲名の部分は差し替えること。

```text
文字が違います。絵はそのままで、タイトルの文字だけ直してください。上段は「ホソミ」の3文字、下段は「アメダンス」の5文字。1文字ずつ確認して、余計な文字を足さないでください。
```

絵は気に入っているのに文字だけ何度も崩れる場合は、文字なしで描かせて、あとから
CSS でカードにタイトルを重ねる手もある。その場合は【タイトルロゴ】の項をまるごと
「文字は一切描かない。左3分の2は文字を置けるように背景だけにする」に差し替える。
