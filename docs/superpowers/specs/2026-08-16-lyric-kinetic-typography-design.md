# 歌詞キネティック・タイポグラフィ強化 設計

2026-08-16

## 目的

プレイ中の歌詞表示(現在は左下固定・フェードのみ)を、MV 風のダイナミックな
キネティック・タイポグラフィにする。方向性は次の3つ。

1. **ビート同期の揺れ** — 表示中の歌詞が BPM に合わせて弾む
2. **行ごとの配置・サイズ変化** — 毎行、位置・角度・大きさが変わる
3. **カタカナ自動強調** — カタカナ語(アメダンス、リズム等)を大きく・色付きで強調

## 方針

DOM + CSS アニメーション拡張(アプローチ A)。Canvas / Three.js 化はしない。
変更は `src/App.tsx`・`src/styles.css`・`src/lyrics.ts` に閉じる。

## 設計

### セグメント分割

- `lyrics.ts` に純関数を追加: 行テキストをカタカナ連続(長音「ー」を含む)と
  それ以外のセグメント列に分割する。
- カタカナセグメントは `.lyric-kw` スパン、それ以外は通常スパンで描画する。

### 行ごとの配置

- 行インデックス + 曲 ID をシードにした決定的乱数(軽量な整数ハッシュ)で
  行ごとに決める:
  - 位置: ノーツレーン(実質 右 370px)を除いた画面内、% 指定(実装は安全側に右 440px+左余白 34px=474px を除外)
  - 回転: ±7° 程度
  - 基本フォントサイズ: 28〜52px
- 決定的なので同じ曲は毎回同じ演出になり、リプレイで安定する。
- 画面端でのはみ出しは `max-width` と位置のクランプで防ぐ。
- キャラや判定テキストとの重なりは許容(ユーザー了承済み)。

### ビート同期

- `60 / BPM` 秒を CSS 変数 `--beat` として `.stage` に設定(BPM は `songs.ts`)。
- 表示中の歌詞は beat 周期で上下に弾む keyframes。文字(セグメント)ごとに
  `animation-delay` をずらして波打たせる。

### カタカナ強調

- `.lyric-kw` は約 1.4 倍サイズ + アクセント色(既存のピンク系に合わせる) +
  揺れ振幅大きめ。

### イン/アウト

- 登場: スケール 0.6 → オーバーシュート → 1 のポップイン(回転しながら)。
- 退場: 縮小 + フェード。
- 現行の `lyricIdx` / `lyricOut` の key 切り替え構造はそのまま使う。

## 確認方法

- `npm run build`(型チェック込み)を通す。
- dev サーバーで実際にプレイし、視認性・レーン非干渉・ビート同期感を目視確認する
  (規約: ゲームロジック周りは型が通るだけでは不十分)。
